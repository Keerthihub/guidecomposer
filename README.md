# Mullion

A layout-grid panel for Adobe Illustrator. Mullion draws column, modular, and baseline grids, composition guides (rule of thirds, golden sections, diagonals, center lines, golden spiral), and patterns (square, dot, isometric, hexagon, diagonal, radial) as editable lines, boxes, or Illustrator guides. Lines can be solid, dashed, or dotted, with their own margin color and shaded gutters. A visual library of 105 layouts, drawn live on your artboard, covers columns, modular grids, asymmetric and classic page proportions, baselines, print, screen, social, composition, and patterns. It works on one artboard, all artboards, or a list such as `1-3, 5`, and keeps grids on their own layer so they can be previewed, hidden, locked, and cleared without touching your artwork.

> **Mullion is a placeholder name.** Check trademarks before you publish, and see [Renaming](#renaming) for every place the name and ids appear.

- Platform: CEP panel extension (not UXP; Illustrator has no UXP support)
- Illustrator 2022 (26.0) or later, macOS and Windows
- No network access, no accounts, no Node.js inside the panel

## Project layout

```text
CSXS/manifest.xml             Extension manifest (host ILST, panel geometry, icons)
client/index.html             Panel markup
client/styles.css             Panel styles; theme tokens are set from Illustrator's colors
client/app.js                 Panel controller: bridge, queue, preview, presets
client/vendor/CSInterface.js  Adobe CEP bridge (v12)
host/index.jsx                ExtendScript entry: boot loader and the Mullion.api endpoints
host/illustrator-adapter.jsx  The only code that touches the Illustrator DOM
host/vendor/json2.js          JSON for ExtendScript (public domain)
shared/grid-core.js           Pure grid geometry and validation (ES3; runs everywhere)

```

## Development

Requires Node.js 20 or later.

```sh
npm install        # installs acorn, used only by the ES3 checker
npm run check      # ES3 compatibility check + all Node tests
npm run test:ui    # headless Chrome smoke test of the panel (needs Google Chrome)
```

`npm run check` must pass before every commit. It verifies that every file Illustrator evaluates parses as ES3 and avoids APIs ExtendScript lacks (such as `Array.prototype.forEach`, `Object.keys`, `String.prototype.trim`, and reserved words like `final` used as property names).

### Work on the UI in a browser

Open `client/index.html` directly in Chrome. Outside Illustrator the panel uses a mock host with three artboards (Letter, a small card, and a poster), so every control works, including artboard lists. URL options:

| Query | Effect |
| --- | --- |
| `?theme=dark` | Illustrator's darkest UI (default) |
| `?theme=mediumdark`, `?theme=mediumlight`, `?theme=light` | Other Illustrator brightness settings |
| `?nodoc` | No document open |

`node scripts/ui-smoke.js --screenshots <folder>` saves screenshots of each state.

## Load the panel in Illustrator

Development builds are unsigned, so Illustrator must be told to allow them. The install scripts turn on `PlayerDebugMode` for CEP 11–13 and link this folder into your user extensions folder.

**macOS**

```sh
scripts/install-dev-mac.sh
```

This links the repository to `~/Library/Application Support/Adobe/CEP/extensions/com.mullion.panel`. Remove the link with `scripts/install-dev-mac.sh --uninstall`.

**Windows** (PowerShell)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install-dev-windows.ps1
```

This creates a junction at `%APPDATA%\Adobe\CEP\extensions\com.mullion.panel`. Remove it with the same command plus `-Uninstall`.

**Then:**

1. Quit and restart Illustrator.
2. Choose **Window > Extensions > Mullion**. Some recent Illustrator versions label this submenu **Extensions (Legacy)**.
3. Dock the panel wherever you like. It remembers settings between sessions.
4. Open **More > Draw test line**. A line across the middle of the artboard confirms the panel, bridge, and host script are all working. **Clear** removes it.

`PlayerDebugMode` affects every CEP extension for your user account. Turn it off when you finish testing (the scripts' header comments show how).

To pick up code changes, close and reopen the panel. Host `.jsx` changes are reloaded when the panel boots.

## Debugging

**Panel (HTML/JS):** with the panel open, visit `http://localhost:8088` in Chrome and choose the Mullion page to get DevTools. The port comes from `.debug`, which is never packaged.

**Host (ExtendScript):** every host error comes back to the panel's status line as a readable message, such as `Illustrator reported an error: ... (line 42)`. The panel also logs the raw host response to the DevTools console when Illustrator returns something unexpected.

**CEP logs:** raise the log level, restart Illustrator, and reproduce the problem.

```sh
# macOS
defaults write com.adobe.CSXS.12 LogLevel 6
# logs: ~/Library/Logs/CSXS/CEP12-ILST.log
```

```powershell
# Windows
Set-ItemProperty -Path "HKCU:\Software\Adobe\CSXS.12" -Name LogLevel -Value "6"
# logs: %TEMP%\CEP12-ILST.log
```

Use `CSXS.11` / `CEP11` for Illustrator 2022. When reporting a problem, include: Illustrator version, OS, the status line text, DevTools console errors, and the relevant lines from the CEP log.

**Host scripts without the panel:** on macOS you can run ExtendScript in Illustrator from the terminal, which is how the adapter was verified during development:

```sh
osascript -e 'tell application id "com.adobe.illustrator" to do javascript "$.evalFile(new File(\"/path/to/test.jsx\"))"'
```

## How it works

```text
client/app.js ── CSInterface.evalScript('Mullion.api.generate("<URI-encoded JSON>")')
      │
host/index.jsx ── decodes payload ─ MullionCore.buildGrid(artboardRect, settings) ─ line segments
      │
host/illustrator-adapter.jsx ── managed layer ─ tagged group ─ PathItems
```

**One geometry engine.** `shared/grid-core.js` converts units to points, validates settings, and returns shapes for an Illustrator rectangle `[left, top, right, bottom]` (Y grows upward, so `top > bottom`): straight segments, boxes, polygons, Bezier curves, and dots. Each shape has a kind that decides its styling: margin lines can take the margin color, gutter boxes are filled, everything else uses the stroke color and line style. The golden spiral is built from quarter circles in a golden rectangle, stretched to the content area and flipped so it converges on the chosen corner. The panel runs the same file to draw its preview and validate as you type, so the panel and the artboard can't disagree.

**No code injection.** The panel never splices values into script source. Every payload is JSON passed through `encodeURIComponent`, whose output contains no quotes, backslashes, or line breaks, and the host decodes it with `decodeURIComponent` and `JSON.parse`.

**Structured responses.** Every endpoint returns `{"ok":true,"data":...}` or `{"ok":false,"error":{"code","message","fields"}}`. Codes: `NOT_READY`, `NO_DOCUMENT`, `INVALID_SETTINGS`, `BAD_PAYLOAD`, `MISSING_FILE`, `BOOT_FAILED`, `UNEXPECTED`.

**Host API** (`Mullion.api`):

`target` is `{ mode: "active" }` (default), `{ mode: "all" }`, or `{ mode: "range", range: "1-3, 5" }` with 1-based artboard numbers.

| Method | Payload | Effect |
| --- | --- | --- |
| `status` | none | Active document and artboard, every artboard's rectangle, grid counts, grid layer visibility and lock |
| `preview` | `{ settings, target, mode }` | Replaces all previews (in every open document) with previews on the target artboards. In replace mode, grids it would replace are hidden until the preview ends |
| `clearPreview` | none | Removes previews from every open document |
| `generate` | `{ settings, target, mode }` | Removes previews and draws a grid on each target artboard. `mode: "replace"` (default) removes the Mullion grids already there; `mode: "add"` keeps them so grid types can be combined |
| `clear` | `{ target }` | Removes Mullion grids (preview and generated) from the target artboards |
| `setGridLayer` | `{ visible?, locked? }` | Shows, hides, locks, or unlocks the Mullion grids layer |
| `drawTestLine` | none | Install diagnostic |

Generate and preview validate **every** target artboard before drawing anything: if the grid doesn't fit one of them, nothing is drawn and the error names that artboard. One request may draw at most 10,000 shapes (2,500 per artboard). Error codes also include `INVALID_TARGET` and `TOO_MANY_SHAPES`.

**Patterns** fill the space between the margins. Square, isometric, and diagonal patterns are families of parallel lines clipped to that area, with one line through its top-left corner. Hexagons are drawn whole (never cut off at the margins) and centered as a block. Radial patterns center their rings and spokes in the area. Dots are filled circles, so they can't be guides.

**Layout library** (`shared/layouts.js`, opened with the **Layouts** button) holds 105 layouts in ten categories. Layouts set layout fields only; color, width, opacity, and line style stay as the user set them.

- *Proportional layouts* (Columns, Modular, Asymmetric, Baseline, Classic) store margins and gutters as fractions of the artboard (its shorter side, or its width and height for the Van de Graaf canon). Applying one converts them into the user's units for the active artboard, so the same layout suits A6 and A0.
- *Fixed layouts* (Print, Screen, Social, and some patterns) carry their own units and the artboard size they were designed for.
- *Suggested* lists layouts made for artboards with the same proportions as the active one (within 2.5%), exact sizes first.
- Each tile's thumbnail is built by the grid engine on the active artboard (fixed layouts on their own size), so it shows how the layout will actually fit. Thumbnails render as tiles scroll into view.

`tests/layouts.test.js` builds every fixed layout on its own size and every proportional layout on A6, A0, Letter, square, 16:9, and 9:16 artboards in points and millimeters.

**Ownership model: why Clear is safe.**

- Every grid is a group carrying three tags: owner (`com.mullion.panel`), kind (`preview`/`final`), and artboard index.
- Every path Mullion draws carries the owner id in its note.
- Only groups with the owner tag are removed. Layer and group names are never used to decide what to delete.
- Before removing a group, any child that isn't a Mullion path (for example art dragged into the grid) is moved out onto the layer, keeping its lock and visibility.
- Locked or hidden layers are unlocked for the operation and restored afterwards.
- The **Mullion grids** layer is deleted only when completely empty, and never when it is the document's last layer.

`tests/host.test.js` proves these rules against a fake Illustrator DOM that enforces Illustrator's lock rules. The same scenarios were also run in Illustrator 30.8.1.

**Replace or add.** Generate replaces the grids on the target artboards unless **Add to existing grids** is checked. A replacing preview hides the grids it would replace instead of drawing on top of them; each grid it hides is tagged, so ending the preview shows exactly those again and never unhides a grid you hid yourself.

**Preview.** Changes are debounced by 200 ms. Host calls run one at a time, and pending previews collapse to the latest settings, so dragging through values never floods Illustrator. Generate and Clear turn preview off.

## Manual QA checklist

Run on the oldest and newest Illustrator versions you support, on both macOS and Windows. Record the Illustrator version, OS, and result for each line.

**Install and launch**

- [ ] Panel appears under Window > Extensions and opens without errors
- [ ] Draw test line works; Clear removes it
- [ ] Panel matches each of Illustrator's four UI brightness settings, including after switching while open
- [ ] Panel resizes and docks cleanly; nothing overflows at its narrowest width
- [ ] Settings and presets survive closing the panel and restarting Illustrator

**Document states**

- [ ] With no document open: "Open or create a document" message, actions disabled
- [ ] Opening a document enables actions without reopening the panel
- [ ] Switching between two documents updates the artboard name and size
- [ ] Clicking a different artboard, then hovering over the panel, updates the readout

**Grids**

- [ ] Columns: 12 columns, 12 pt gutter, 36 pt margins on Letter give column edges at x = 36, 70, 82 … 576 (check with the Transform panel)
- [ ] Modular grid with rows and row gutters lines up with the panel drawing
- [ ] Baseline grid: first line at top margin plus offset; the last line lands on the bottom margin when the spacing divides evenly
- [ ] Every unit (pt, px, mm, in) gives the same grid after conversion
- [ ] Asymmetric margins produce the expected content box
- [ ] Extend to artboard edges runs lines to the artboard boundary
- [ ] Second artboard placed away from the origin: grid lands on that artboard
- [ ] Apply to All artboards and Chosen artboards (`1, 3`): one grid per artboard; Clear follows the same choice
- [ ] Chosen artboards with a bad list (`0`, `9`, `a`) shows an inline error and disables Generate and Clear
- [ ] A grid that fits one artboard but not another: nothing drawn, and the message names the artboard
- [ ] Very small artboard (for example 20 × 20 pt) and very large column/row counts (100 × 100)
- [ ] Guides output creates real guides (View > Guides > Hide Guides hides them)
- [ ] Boxes output: one closed rectangle per column or module; Boxes disappears for baseline and composition
- [ ] Composition: thirds, golden sections, diagonals, and center lines line up with the panel drawing
- [ ] Golden spiral: smooth curve (Direct Selection shows smooth points), converges on each of the four focus corners, on landscape and portrait artboards, and as a guide
- [ ] − / + buttons step columns and rows; holding repeats; Shift-click steps by 10
- [ ] Patterns: square, isometric, and diagonal lines stop at the margins; hexagons are whole and centered; radial rings are smooth circles; dots are filled with no stroke
- [ ] Isometric lines meet at shared points (zoom in on an intersection)
- [ ] Line styles: dashed and dotted strokes scale with stroke width; dotted uses round dots
- [ ] Margin color colors only the margin lines; shaded gutters are filled, semi-transparent, sit beneath the lines, and don't double up where row and column gutters cross
- [ ] Layouts button opens the library in place of the settings; Done and Escape close it and return focus to the button
- [ ] Suggested shows layouts for the active artboard's shape (try Letter, A4, 1080 × 1080 px, and 1920 × 1080 px artboards); switching artboards while the library is open updates the suggestions and thumbnails
- [ ] Thumbnails match what Generate draws; a layout that doesn't fit the artboard says so on its tile
- [ ] Proportional layouts scale margins to the artboard (compare the same layout on A6 and A3); fixed layouts keep their units; your color and line style are unchanged
- [ ] Lines output: color, width, and opacity match the panel
- [ ] CMYK document: stroke color is a CMYK color
- [ ] Eye button hides and shows the Mullion grids layer; lock button locks and unlocks it; both reflect changes made in the Layers panel after hovering over the panel
- [ ] Generating into a hidden grid layer shows it again; grid layer is non-printing
- [ ] Collapsing the drawing and the Appearance section is remembered after reopening the panel

**Preview and safety**

- [ ] Preview follows edits, including fast typing and holding arrow keys
- [ ] Turning preview off removes the preview; Generate replaces it with a real grid
- [ ] Switching documents while previewing leaves no preview behind in the first document
- [ ] Clear removes only Mullion grids on the artboards chosen in Apply to
- [ ] Generating twice leaves one grid (the status line says "Replaced"); with Add to existing grids checked, grids stack
- [ ] While previewing over an existing grid, the old grid is hidden; turning preview off shows it again; a grid you hid in the Layers panel stays hidden
- [ ] Art on the Mullion layer, art dragged into a Mullion group, and look-alike groups all survive Clear
- [ ] A locked or hidden Mullion layer can still be generated into and cleared
- [ ] Undo after Generate and after Clear: note how many undo steps each takes
- [ ] Invalid input (0 columns, gutters wider than the page) shows inline errors and never draws

**Keyboard and accessibility**

- [ ] Every control is reachable with Tab and shows a visible focus ring
- [ ] Arrow keys step number fields; Shift + arrow steps by 10
- [ ] Cmd/Ctrl + Enter generates
- [ ] Typing in panel fields doesn't trigger Illustrator tool shortcuts

## Known limitations

- **Artboard changes have no event.** Illustrator doesn't notify extensions when the active artboard changes, so the panel re-reads the document when it gains focus, when the pointer enters it, and when documents switch.
- **Grids are found in top-level layers only.** A Mullion grid moved into a sublayer or wrapped in another group is left alone by Clear. Delete it manually.
- **Artboard tags store the index.** After reordering or deleting artboards, Clear may treat a grid as belonging to a different artboard. Set Apply to All artboards and Clear.
- **Hexagons are whole.** Hexagon patterns leave an even gap at the margins instead of cutting hexagons in half.
- **Dots and gutter fills can't be guides.** Illustrator guides are strokes, so dots switch to lines and gutter shading is skipped for guides.
- **Ready-made layouts don't resize artboards.** They set margins, columns, and units for the size named in the status line; set the artboard size in Illustrator.
- **The spiral stretches to the content area.** On areas that aren't golden rectangles it becomes elliptical, which is usually what layout work needs. Set margins so the area is 1 : 1.618 for a true golden spiral.
- **Undo granularity** depends on how Illustrator records script changes. Check it during QA (see checklist); previews may add undo history.
- **Guide color** comes from Illustrator's preferences, not from the panel.

## Renaming

"Mullion" and its ids appear in:

| Where | Value |
| --- | --- |
| `CSXS/manifest.xml` | `ExtensionBundleId`, both `Extension Id`s, `ExtensionBundleName`, `<Menu>` |
| `.debug`, install scripts, `scripts/release-checks.js` | extension ids |
| `host/index.jsx` | `$.global.Mullion`, `M.OWNER_ID` |
| `host/illustrator-adapter.jsx` | layer name `Mullion grids`, tag names |
| `shared/grid-core.js` | global `MullionCore` |
| `client/app.js` | storage keys `mullion.*`, `Mullion.api` calls |
| `client/index.html`, `package.json`, docs | product name |

Choose the final id before your first public release. Changing `M.OWNER_ID` or the tag names later means Clear no longer recognizes grids made by earlier versions.
